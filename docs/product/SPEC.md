> 本文件依目前的互動 demo（`../../demo/index.html`）撰寫，作為正式開發的依據。
> 內容涵蓋三大部分：**功能介面**、**美術風格**、**每一個邏輯**。

## 0. 產品概述

- **目的**：協助國小低年級的老師與家長溝通。老師在後台發布一次，家長在手機上一眼看懂「今天功課、明天要帶、孩子今天的狀況、成績、班級大小事」。
- **定位（為什麼贏過 LINE 群組＋紙本聯絡簿）**：
  - **結構化、不洗版**：公告、聯絡簿、行事曆、請假、成績各有專區，重要資訊不會被閒聊洗掉。
  - **可回報 / 可追蹤**：公告有「已讀回條」、同意書有「已簽名單」、請假有「審核狀態」，老師一眼看到誰還沒處理，不用一則則追。
  - **老師更省力**：範本一鍵套用、複製昨天聯絡簿、成績只 key 分數自動算級距、一鍵提醒未簽/未讀。
  - **家長更省心**：只看自己孩子、極簡有重點；行事曆、請假、私訊都在一處，不用打電話、不用在群組公開發問。
  - **情感護城河**：孩子的照片、亮點、里程碑、成績自動累積成「成長時間軸／紀念冊」，學期末可留存匯出——這是 LINE 洗掉即失、紙本做不到的價值。
- **形態**：手機優先的 Web App。分「家長端（前台）」與「老師端（後台）」兩套介面。
- **目前 demo 狀態**：純前端，資料存在瀏覽器 `localStorage`（key：`banjilian_demo_v4`；非真實資料庫、無帳號驗證）。正式版差異見 §7。

## 1. 使用者角色

| 角色 | 說明 | 權限 |
| --- | --- | --- |
| 老師（導師） | 一人管理全班 | 新增/編輯/刪除所有內容、登記成績、審核請假、追蹤同意書、回覆私訊、控制欄位是否對家長顯示 |
| 家長 | 一個帳號綁一個孩子（一對多） | 只能查看自己孩子的資料、勾選聯絡簿完成、回報已讀、線上簽同意書、線上請假、私訊老師 |

## 2. 功能介面（Information Architecture）

介面採「**底部分頁（Tab）＋子畫面（覆蓋層 View）**」兩層結構：
- **分頁**：最高頻的主功能，常駐底部。
- **子畫面 View**：次要/情境功能，由首頁快速操作或卡片進入，頂端有「‹ 返回」，返回不改變原本停留的分頁。

### 2.1 家長端（前台）· 主色 青綠

底部分頁（**依內容動態出現**）：

| 順序 | 分頁 | 是否恆常顯示 | 出現條件 |
| --- | --- | --- | --- |
| 1 | 🏠 首頁 | 是 | — |
| 2 | 📒 聯絡簿 | 是 | — |
| 3 | 📣 公告 | 是 | — |
| 4 | 🌱 成長 | 否 | 老師**已開啟**成長功能（L16）**且**有發布「文字紀錄 / 照片 / 里程碑」（L2）時才出現 |
| 5 | 📊 成績 | 否 | 老師**已開啟**成績功能並「在家長端顯示成績」（L16）時才出現 |

> 進階分頁 / 入口（成長、成績、行事曆、請假、同意書）一律受 **L16 功能開關**控制，並疊加 **L2 有發布才顯示**。核心 3 項（聯絡簿、公告、聯絡老師）恆常顯示。

家長端子畫面 View（由首頁快速操作或卡片進入）：

| View | 入口 | 功能 |
| --- | --- | --- |
| 📅 行事曆 | 首頁快速操作 | 考試/活動/繳費/放假一覽、加入手機行事曆 |
| 🤒 請假 | 首頁快速操作 | 線上請假、查看送出後的審核狀態 |
| 💬 聯絡老師 | 首頁快速操作 | 一對一私訊，標示老師回覆時段 |
| 📖 成長紀念冊 | 成長分頁封面 | 學期統計＋亮點＋相片牆，可匯出留存 |

### 2.2 老師端（後台）· 主色 暖橘

底部分頁（固定五個）：

| 順序 | 分頁 | 功能 |
| --- | --- | --- |
| 1 | 📋 總覽 | 班級即時動態、**今日待辦**、統計、快速捷徑 |
| 2 | 📣 公告 | 新增/刪除公告、範本、排程、看**已讀率** |
| 3 | 📒 聯絡簿 | 編輯今日作業/明日攜帶、**複製昨天**、看家長完成統計 |
| 4 | 🌱 成長 | 新增/刪除文字紀錄與照片 |
| 5 | 📊 成績 | 輸入各生分數、控制顯示/公開開關 |

> **預設精簡（L16）**：新班級只亮**核心 3 項**（公告、聯絡簿、聯絡老師）；成長、成績等分頁待老師於「⚙️ 設定 / 更多功能」逐一開啟後才出現。首次進後台會有 ≤ 3 步導覽（L17）。

老師端子畫面 View（由總覽「今日待辦」或「設定」進入）：

| View | 入口 | 功能 |
| --- | --- | --- |
| ⚙️ 設定 / 更多功能 | 總覽 / 頂列 | 功能開關清單（每項一句話說明 + 開關，L16）、重看導覽（L17） |
| 🤒 請假審核 | 待辦：請假待審核 | 逐筆核准 / 未核准 |
| ✍️ 同意書追蹤 | 待辦：未簽同意書 | 已簽/未簽名單、簽署進度、一鍵提醒未簽 |
| 💬 家長訊息 | 待辦：家長私訊 | 回覆家長私訊 |

## 3. 畫面逐一說明（功能介面細節）

> 共同結構：每個畫面 = 狀態列 + 彩色標題列（班級膠囊 + 襯線大標題，子畫面時左上顯示「‹ 返回」）+ **浮起圓角內容面板**（含頂部握把）+ 底部分頁。

### 3.1 家長端

#### A. 登入
- 元件：Logo、標題「歡迎回來」、輸入框「座號 / 姓名」、密碼框、主按鈕「進入我孩子的專屬清單」、隱私說明。
- 行為：按主按鈕即進入首頁（demo 不驗證密碼）。

#### B. 首頁（Dashboard，最高頻）
- **主角區塊 feature（青綠）**：完成度**環形進度**（%）+ 襯線大標題「還有 N 項要完成 / 全部完成！/ 今天沒有作業」+ 副標。
- **快速操作（3 顆）**：📅 行事曆、🤒 請假、💬 聯絡老師 → 進入對應子畫面。
- 卡片「✍️ 今日作業」、「🎒 明天要帶」（膠囊標籤）。
- **待簽同意書卡**：`該孩子尚未簽署`時出現，內含「✍️ 立即線上簽署」。
- 卡片「最新公告」：最新一則；未讀顯示「我已閱讀」按鈕，已讀顯示「✓ 已讀」。
- 卡片「🎯 最新成績」：**成績已發布**時出現，點擊跳成績頁。
- 卡片「📸 今天的孩子」：**有照片**時出現。

#### C. 聯絡簿
- 提示條：勾選會同步到老師端完成人數。
- 卡片「今日作業 / 明日攜帶」：每列**可點勾選框**（帶勾選動畫）。空狀態友善文案。

#### D. 公告
- 頂部提示：可點「我已閱讀」，取代群組洗「收到」。
- 卡片列表：重要紅標 / 一般藍標；標題、內文、時間；未讀顯示「我已閱讀」，已讀顯示「✓ 已讀」。
- 空狀態：「目前沒有公告 📭」。

#### E. 成長（分頁僅在有內容時出現）
- **成長紀念冊封面卡**（青綠→橘漸層）：入口「翻閱紀念冊 →」。
- **成長時間軸**：垂直時間線，逐項為里程碑（粉點）/ 成績里程碑（橘點）/ 老師亮點（青點），含表情、標題、描述、日期。逐項淡入動畫。
- 卡片「📸 最近照片」。

#### F. 成長紀念冊（子畫面 View）
- 大封面（學期 · 班級 · 孩子名）。
- 統計格：照片數、老師亮點數、里程碑數、最近成績。
- 卡片「✨ 學期亮點」（里程碑＋亮點合併，取前 6）。
- 卡片「📸 相片牆」。
- 結尾價值訴求：「LINE 洗掉就找不到；這裡一直留著、可匯出成冊」。

#### G. 行事曆（子畫面 View）
- 事件清單：左側日期（襯線大日 + 月），中間標題 + 完整日期，右側**類型膠囊**（評量/活動/繳費/放假，各有語意色）。
- 底部「＋ 一鍵加入手機行事曆」（demo 示意）。

#### H. 請假（子畫面 View）
- 表單：假別下拉（病假/事假/遲到）、日期、原因多行、按鈕「送出給老師」。
- 送出後「我送出的請假」列表：顯示假別、日期、原因與**狀態膠囊**（待審核/已核准/未核准）。

#### I. 聯絡老師 · 私訊（子畫面 View）
- 頂部提示老師回覆時段（非上班免打擾）。
- 對話氣泡：老師（左/白）、家長（右/青），含時間；新訊息彈入動畫。
- 底部輸入列 + 送出鈕；註明「一對一，其他家長看不到」。

### 3.2 老師端

#### A. 總覽
- **主角區塊 feature（暖橘）**：作業完成度環 + 「家長完成 done/total 項作業」。
- **今日待辦卡（核心賣點）**：三張 alert —
  - 🤒 `N 筆請假待審核` → 前往【請假審核】
  - ✍️ `N 位未簽同意書`（含名稱與截止日）→【同意書追蹤】
  - 💬 家長私訊（含回覆時段）→【家長訊息】
- 統計格（4 格）：班級人數、作業已勾完成、公告數、明日攜帶。
- 快速捷徑（4 顆）：發公告 / 寫聯絡簿 / 記成長 / 登成績。

#### B. 公告
- **常用範本 chips**：一鍵把範本套進標題/內文，再微調（回家作業提醒、天氣提醒、活動預告）。
- 新增表單：標題、內文、「標記為重要」開關、**排程發布**欄（demo 示意）、按鈕「發布給全班家長」。
- 已發布列表：每則顯示時間與**已讀 X/班級人數**，可刪除。

#### C. 聯絡簿
- 提示條：家長已完成 done/total（即時）。
- **「⟳ 複製昨天的聯絡簿」**：一鍵帶入前一天內容再微調。
- 「今日作業」「明日攜帶」：現有項目 + 刪除；底部新增列。

#### D. 成長
- 新增文字紀錄：表情下拉、標題、描述、「發布到家長端」；下方已發布列表（可刪除）。
- 照片紀錄：照片牆（可刪除）+ 新增。

#### E. 成績
- 開關卡：①「在家長端顯示成績欄位」②「公開全班級距」。
- 「考試名稱」輸入。
- 「輸入各生分數」：全班名單，每人一個分數框（留空＝未登記；孩子那列標「示範帳號」）。
- 「系統自動算出的級距」即時預覽。
- 底部按鈕顯示同步狀態。

#### F. 請假審核（子畫面 View）
- 逐筆卡片：學生（座號）、假別、日期、原因、狀態膠囊。
- `待審核`者顯示「核准 / 未核准」；處理後狀態即時更新，並同步家長端。
- 空狀態：「目前沒有待審核的請假 ✅」。

#### G. 同意書追蹤（子畫面 View）
- **主角區塊 feature（暖橘）**：簽署率環 + 「已簽 X/總數」+ 截止日。
- 「📣 一鍵提醒 N 位未簽家長」按鈕（未簽>0 才出現）。
- 名單卡：❌ 未簽（座號、姓名、紅「未簽」）／✅ 已簽（綠「已簽」）。

#### H. 家長訊息（子畫面 View）
- 與該家長的對話：家長（左/白）、老師（右/橘），含時間。
- 底部輸入列 + 送出鈕；註明「有明確回覆時段，不用 24 小時待命」。

## 4. 每一個邏輯（Business Logic）

> 這是開發時要嚴格實作的規則。

### L1. 一對多帳號與資料隔離
- 一個家長帳號對應一個孩子（以座號/姓名識別）。
- 家長只能讀取「自己孩子」的資料；不可看到其他孩子的個資、確切成績、私訊。

### L2. 有發布才顯示欄位（Conditional Display）— **核心**
- 家長端**不顯示空欄位**，不可出現「成績－無」佔位。
- 規則：
  - 「成長」分頁：`notes.length>0 || photos.length>0 || milestones.length>0` 才出現。
  - 「成績」分頁：`grades.published===true` 才出現。
  - 首頁「最新成績」卡：`grades.published && 該孩子有分數` 才出現。
  - 首頁「今天的孩子」卡：`photos.length>0` 才出現。
  - 首頁「待簽同意書」卡：`consent 且該孩子 seat 未在 signed 內` 才出現。
- 分頁若因條件消失且使用者正停留其上 → 自動退回「首頁」。

### L3. 聯絡簿勾選與完成統計（雙向同步）
- 家長勾選 → 切換該項 `done`；老師端「家長已完成 X/Y」、總覽統計與完成環**即時更新**。
- 完成度 = `已完成 / 總數 × 100`（無項目視為 100%）。

### L4. 成績邏輯
- **老師只輸入各生分數**，系統自動分桶算級距（`90–100 / 80–89 / 70–79 / 60–69 / 59 以下`），留空不計；長條寬度自動縮放。
- **隱私分級**：個人確切分數僅該家長可見；全班級距為去識別化（各分數帶人數），需老師開「公開級距」。
- **percentile**：孩子「勝過班上 X%」= `低於孩子分數的人數 / 已登記總數 × 100`。
- **兩個開關**：`published`（關→整個成績分頁與首頁成績卡消失）、`showDist`（關→只看自己分數、不顯示級距圖）。

### L5. 公告已讀回條
- 每則公告有 `read`（本帳號是否已讀）與 `others`（其他已讀人數基數，demo 模擬）。
- 家長點「我已閱讀」→ `read=true`，按鈕改為「✓ 已讀」。
- 老師端公告列表顯示 **已讀數 = `others + (read?1:0)`** / 班級人數，即時反映。

### L6. 線上請假流程（雙向）
- 家長於【請假】送出 → 新增一筆 `status='pending'`（含 seat、姓名、假別、日期、原因）。
- 老師【請假審核】按核准/未核准 → `status` 改 `approved`/`rejected`。
- 兩端狀態即時同步：老師總覽待辦數、家長「我送出的請假」狀態同步變更。

### L7. 同意書簽署與追蹤（雙向）
- `consent.signed` 為 `{ seat: true }` 對照表。
- 家長於首頁「立即線上簽署」→ `signed[該孩子seat]=true`，首頁待簽卡消失。
- 老師【同意書追蹤】即時反映簽署率、已簽/未簽名單；老師總覽「未簽 N 位」同步更新。
- 「一鍵提醒未簽」對未簽名單發提醒（demo 以 toast 表示）。

### L8. 一對一私訊
- `messages.list` 為時間序訊息陣列，`from` ∈ `teacher | parent`；`officeHours` 為回覆時段。
- 家長送出 → `from:'parent'`；老師送出 → `from:'teacher'`；兩端即時互見。
- 顯示規則：檢視者自己的訊息靠右（家長青、老師橘），對方靠左白底。

### L9. 成長時間軸 / 紀念冊（衍生視圖，不另存）
- 時間軸由 `milestones`（里程碑）＋ 成績里程碑（`grades.published` 且有分數時自動生成一筆）＋ `notes`（老師亮點）合併呈現。
- 紀念冊統計（照片/亮點/里程碑/最近成績）皆為即時計算。

### L10. 行事曆
- `events` 陣列（含 `date`、`title`、`type`）；`type` ∈ `exam | activity | fee | holiday`，各對應語意色與中文標籤。
- 「加入手機行事曆」demo 以 toast 示意；正式版產生 `.ics` / 呼叫系統行事曆。

### L11. 老師省力機制
- **公告範本**：`ANN_TMPLS` 一鍵填入標題/內文。
- **複製昨天聯絡簿**：一鍵以前一天內容覆蓋今日作業/攜帶，供微調。
- **成績**：只 key 分數自動算級距（見 L4）。
- **一鍵提醒**：未簽同意書（L7）、公告未讀可延伸。

### L12. 老師發布 → 家長即時可見
- 老師任何新增/刪除/編輯（公告、作業、攜帶、成長、照片、分數、開關、審核、回覆）都**立即反映到家長端**。
- Demo 兩端共用同一份狀態；正式版以後端＋即時更新（見 §7）。

### L13. 資料持久化
- Demo：資料存 `localStorage`（key `banjilian_demo_v4`）；重新整理不遺失。
- 「重設 Demo 資料」：清除儲存、回到預設、登出、回到初始分頁。
- 正式版：後端資料庫，帳號登入、跨裝置共用同一份班級資料。

### L14. 空狀態（Empty States）
- 任何清單為空都要有友善文案＋圖示（無公告、無請假、無照片…），不可留白。

### L15. 渲染 / 互動 / 導覽效能規則
- 點擊分頁**只重繪操作的那一側**（家長/老師互不干擾）。
- **子畫面 View** 由首頁快速操作/待辦進入，頂端「‹ 返回」回到原分頁；切換分頁會清掉 View。
- 換頁/進出 View 才播淡入動畫；資料同步更新時保留捲動位置、不重播動畫。
- 表單輸入（公告、聯絡簿、成長、請假原因、私訊）在他側更新時不遺失（compose 暫存）。

### L16. 漸進式功能開放（Progressive Feature Gating）— **核心易用性**
> 目標：老師端**第一眼只看到最核心的功能**，降低認知負擔；其餘功能由老師自行、逐一開啟。家長端隨老師開啟而「逐步長出」新分頁，形成「系統持續進化」的體感（實際上後端一開始就全做好了）。

- **每個班級**有一組「功能開關」（class-scoped feature flags），由**該班老師**掌控；家長端只讀、依開關顯示對應分頁/入口。
- **預設開啟（核心 3 項，不可關閉）**：
  1. 📣 **公告**（含已讀回條）
  2. 📒 **聯絡簿**（今日作業 / 明日攜帶 + 完成統計）
  3. 💬 **聯絡老師**（一對一私訊）
- **預設關閉、老師可逐一開啟（進階項）**：
  - 📊 成績　- 🌱 成長紀錄／相簿　- 📅 行事曆　- 🤒 線上請假　- ✍️ 同意書
- **開啟方式**：老師端「設定 / 更多功能」提供功能清單，每項一句話說明價值 + 一個開關；開啟即在兩端生效（沿用 L12 即時可見）。
- **與 L2 的關係**：L2「有發布才顯示」仍成立，且**疊加在開關之上**——某功能必須「已開啟」**且**「有內容」才會在家長端出現分頁/入口（開關 = 老師意圖；L2 = 有無資料）。
- 關閉某進階功能只是**隱藏入口**，不刪資料；再次開啟即恢復（避免資料遺失，呼應金律 6）。
- 核心 3 項與進階項的**確切清單可調整**，但「預設精簡、逐步開放」的原則不可違背。

### L17. 功能導覽（Onboarding / Guided Tour）— **簡短、不冗長**
> 目標：用「設計本身」溝通為主，導覽為輔。導覽只在**首次使用**或**首次開啟某功能**時出現，短而精，可隨時略過。

- **兩種導覽形態**：
  1. **首次進入老師後台**：≤ 3 步的歡迎導覽（重點：核心 3 項在哪、如何加學生 / 發邀請、去哪開更多功能）。
  2. **開啟某進階功能後**：該功能的**單張**一句話提示（point-out），指出主要操作按鈕即可。
- **文案規則**：每步 ≤ 1 句、聚焦「這裡能做什麼」；禁止長段落、禁止一次爆多個氣泡。
- **可控性**：一律提供「略過 / 下一步」；**看過一次就不再自動出現**（每位老師 + 每個功能各記一次）。可在「設定」手動「重看導覽」。
- **家長端**：原則上**不強加導覽**（介面應自明）；至多在**首次綁定成功**後給一則歡迎提示，說明「只會看到自己孩子的資料」。
- **視覺**：沿用 demo 既有的卡片 / Pill / 動態 token（DESIGN.md），不得新增視覺原語；導覽層為輕量遮罩 + 指向，符合「反 AI-slop」。

## 5. 美術風格（Art Style）

> 完整 token 見 `../design/DESIGN.md`；此處為開發速覽。

### 5.1 美學方向
- **Warm Editorial（溫暖編輯風）＋ Soft Depth（柔和層次）＋ Bold Feature（彩色主角區塊）**。
- 每個畫面只有一個視覺主角（首頁＝完成度、成績＝分數、同意書＝簽署率）。
- 質感目標：精緻親子刊物 App —— 溫暖、可信、專業，不幼稚、不花俏。

### 5.2 色彩（語意化，不可隨意換）
- 家長端主色 `--primary #2f9e8f`（青綠＝信任/教育）。
- 老師端／明日攜帶／孩子自身成績／繳費 `--accent #f2994a`（暖橘）。
- 重要 / 未簽 / 評量 `--pink #ef6f7b`；一般資訊 / 放假 `--blue #4a86c5`。
- 頁面暖白底 `--paper #fbfaf7`；文字 `--ink #212a33`；分隔線 `--line #e9edf1`。

### 5.3 字體
- 大標題 / 大數字 / 時間軸日期 / 行事曆日：`Noto Serif TC`（900）。
- 介面內文：`Noto Sans TC`（400/700/900）。
- 標題字距收緊、行高 1.1；內文行高 1.5–1.6。

### 5.4 版式與元件
- **圖層**：彩色標題列 → 圓角浮起面板（負 margin 疊上、頂部握把）。
- **feature 主角區塊**：彩色漸層卡 + 白字 + 環形進度（SVG）。
- **卡片**：白底、圓角 20、雙層陰影。
- 新增元件：
  - **快速操作 qa**：三格圖示按鈕（首頁）。
  - **時間軸 timeline**：漸層縱線 + 彩色節點 + 卡片，逐項淡入。
  - **紀念冊封面 book**：青→橘漸層、襯線大標、翻閱鈕。
  - **行事曆 cal-item**：日期塊 + 標題 + 類型膠囊。
  - **私訊氣泡 msg-b**：左右分向、彈入動畫、輸入列 + 圓角送出鈕。
  - **待辦 alert**：圖示 + 文案 + 「前往」膠囊。
  - **名單狀態 rl**：座號塊 + 姓名 + 已簽/未簽膠囊。
  - **範本 chip、已讀標記、ghost 按鈕（複製昨天/加入行事曆）**。
- 圓角：卡片 20、按鈕/氣泡 13–16、手機外框 50、標籤 999。

### 5.5 動態（只用於強化層次）
- 換頁 / 進出 View 淡入（fadeUp）、時間軸逐項 stagger、私訊氣泡彈入（pop）、hover 上浮、環形與長條依數值呈現。
- 禁止：無意義輪播、炫技動畫。

### 5.6 反 AI-slop（禁止事項）
- ❌ 通用字體（Inter/Roboto/Arial）；❌ 紫色科技漸層；❌ 整頁等大卡片堆疊無層次；❌ 空欄位佔位「成績－無」。

## 6. 資料模型（Data Model，供後端設計參考）

```
Class     { id, name, date, classSize }
Student   { seat, name, score? }              // 家長帳號綁定對象；分數可空

Announcement { id, title, body, important(bool), time,
               read(bool),        // 本帳號是否已讀
               others(int) }      // 其他已讀人數（demo 模擬；正式版由後端統計）

HomeworkItem    { id, text, note?, done(bool) }   // 今日作業
BringItem       { id, text, note? }               // 明日攜帶
PerformanceNote { id, emoji, title, desc, time }  // 老師亮點（文字紀錄）
PerformancePhoto{ id, label, image }              // 照片
Milestone       { id, emoji, title, desc, time }  // 成長里程碑

CalendarEvent { id, date, title, type }           // type: exam|activity|fee|holiday
Leave         { id, seat, name, date, type, reason,
                status }                          // status: pending|approved|rejected
Consent       { title, deadline, signed: { seat: true } }
Messages      { officeHours, list: [ { id, from, text, time } ] } // from: teacher|parent

Grades {
  published(bool), showDist(bool), exam(name)
  // 個人分數存在 Student.score；級距/percentile 為即時計算，不落庫
}
```

- 級距、percentile、成長時間軸、紀念冊統計、公告已讀數、簽署率皆為**計算值**，不另存。

## 7. Demo 與正式版差異（開工重點）

| 項目 | Demo 現況 | 正式版需要 |
| --- | --- | --- |
| 資料儲存 | 瀏覽器 localStorage | 後端資料庫（每班一份、跨裝置） |
| 帳號 | 無驗證、單一示範帳號 | 老師/家長登入；家長帳號綁孩子、密碼 |
| 多家長共用 | 各瀏覽器各自一份 | 全班共用同一資料，老師改→所有家長看到 |
| 即時更新 | 同頁面共用狀態 | WebSocket / 輪詢 / 推播 |
| 公告已讀 | 單帳號 + 模擬基數 | 每位家長真實已讀狀態與統計 |
| 請假 / 同意書 | 前端狀態切換 | 後端流程、通知、稽核紀錄、時間戳 |
| 私訊 | 單一對話、本地 | 每位家長獨立對話串、通知、封存 |
| 行事曆 | 靜態事件 + toast | 事件管理、產生 .ics / 系統行事曆整合、天氣連動提醒 |
| 照片 / 紀念冊 | 色塊示意 | 真實上傳、壓縮、隱私（他人入鏡處理）、匯出 PDF/相冊 |
| 成績隱私 | 前端控制 | 後端權限控管 |
| 通知 | 無 | 推播 / Email（重要公告、成績、請假結果、未簽提醒） |
| 多語 / 無障礙 | 未做 | 多語系、字級放大（照顧新住民與隔代家庭） |

### 建議技術方向（可討論）
- 前端：單頁 Web App（React / Vue），沿用本 demo 的元件與 token。
- 後端：輕量 BaaS（Firebase / Supabase）可快速起步，含 Auth + DB + 即時同步 + 儲存 + 推播。
- 部署：靜態前端放 Netlify / Vercel / Cloudflare Pages。
